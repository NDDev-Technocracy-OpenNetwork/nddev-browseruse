Standalone Apache-2.0 browser automation. Source: `{{source}}`.

The accepted main commit reuses successful dev check/native/security runs. Publication assembles
the exact tested Linux/macOS/Windows packets without rebuilding the application, then downloads
every uploaded asset and checks its size and SHA-256 before publishing. Measured browser
outcomes, platform skips and immutable run/artifact identities are in `QUALIFICATION.json`.

Install the Bun version pinned by the packet separately and register the matching native host
before loading the extension. Finish active sessions before changing native registration.
Loading the extension and store submission remain owner actions. Chrome updates the existing
listing; Edge's future assigned ID and real Edge acceptance remain required. Physical Android
and NDS adoption are tracked separately. Old unmarked groups require an explicit owner handoff.
